## Purpose and use

Evaluator-only factual reference for Scenario V3. Apply only the section bound to the exact saved scenario text. General standards for the six dimensions belong to the Evaluation Prompt. These rows provide scenario evidence, not a required answer outline, a separate score, or count-based score caps. Correct handling can be implicit; investigate an unknown only when it materially affects understanding or advice. Judge material findings under the selected rubric, without mechanically penalizing every unmentioned fact or counting one defect repeatedly. Do not send this checklist to the Response Agent. Use as an external supplement with Evaluation Prompt V2; do not append it to Evaluation Prompt V3, which already contains the old Scenario V2 Checklist V2. This checklist does not change the selected rubric's score scale or output schema.
