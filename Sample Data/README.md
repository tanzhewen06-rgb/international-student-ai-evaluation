# Sample Data

Actual model-generated research data, including historical pilot batches.

- responses/: generated answers grouped by original batch.
- evaluations/: trials, supplements and analysis-ready exports.
- analysis/: saved offline analyses.
- reference_data/: frozen baseline metadata and numeric scores.

Local archives and machine-specific migration records are excluded.
Metadata uses project:// references resolved from this project's own root.

The final Type 1 dataset has 125 answers and 375 effective judge records,
including five provisional records. The completed combined data is:
